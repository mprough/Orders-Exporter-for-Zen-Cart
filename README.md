# Orders-Exporter-for-Zen-Cart
Orders Exporter allows you to download orders from your Zen Cart shop to a tab delimited text file, which can be edited (printed, saved) in MS Excel, or better still OpenOffice.  There are four different download types so you can choose what info you want to export.

Zen Cart Repo: https://www.zen-cart.com/plugins/orders-exporter-vb560
